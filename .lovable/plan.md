# فاتورة قابلة للتحميل بعد الدفع عبر سداد

## الهدف
بعد نجاح الدفع، يستطيع العميل تحميل فاتورته مباشرة بضغطة واحدة — بدون إعادة توجيه تلقائية للصفحة الرئيسية.

## ما سيراه العميل
شاشة نجاح فاخرة (ذهبي/كحلي، RTL، خط Tajawal) تعرض:
- شارة "تم الدفع بنجاح" + اسم الفعالية وتاريخها
- الاسم، رقم الهاتف، الجنسية
- نوع التذكرة، عدد التذاكر المدفوعة، المبلغ الإجمالي (ر.ق)
- رقم الحجز + رقم عملية سداد (payment_id) + تاريخ/وقت الدفع
- رموز QR للتذاكر
- زر رئيسي: **تحميل الفاتورة (PDF)**
- زر ثانوي: **حفظ كصورة (PNG)**
- زر: العودة للصفحة الرئيسية (يدوي فقط)

## القرارات
- **بدون أي تكلفة**: التوليد يتم في المتصفح.
  - PDF: نافذة طباعة HTML → "حفظ كـ PDF" (نفس أسلوب `generateInvoicePdf` الحالي، مجاني، بدون مكتبات إضافية).
  - PNG: التقاط عنصر الفاتورة عبر `html-to-image` (مكتبة مجانية خفيفة) للموبايل.
- **إلغاء العدّاد التلقائي** في صفحة التأكيد حتى لا يفقد العميل الفاتورة؛ العودة للرئيسية بالضغط فقط.

## التغييرات التقنية
1. `src/lib/generateInvoicePdf.ts` — إضافة حقول: `payment_id` (رقم عملية سداد)، `paid_at`، `payment_method`، وتحسين التصميم (رأس ذهبي، بطاقة ملخّص، جدول أنيق) مع الحفاظ على التوافق مع `InvoiceTab`.
2. `src/components/InvoiceCard.tsx` (جديد) — بطاقة الفاتورة الفاخرة المعروضة على الشاشة + أزرار التحميل (PDF/PNG).
3. `src/pages/Confirmation.tsx` — جلب بيانات العميل والفعالية و`ticket_holders`/QR، عرض `InvoiceCard`، إزالة العدّاد والتحويل التلقائي.
4. `src/pages/SadadCallback.tsx` — بعد النجاح، الانتقال إلى `/confirmation` خلال ~2 ثانية بدل 8، وحفظ `orderIds` كما هو (لا تغيير في منطق الدفع أو الويبهوك).
5. إضافة حزمة `html-to-image` فقط.

## ما لن يتغيّر
منطق سداد، الويبهوك، تأكيد الطلبات، الأرشفة، أو أي بيانات في قاعدة البيانات.
